# Streaming Demo

Token-by-token LLM output streaming via `--stream` flag.

## Usage

```bash
# Stream tokens in real-time
yamlgraph graph run examples/demos/streaming/graph.yaml --var topic="streaming" --stream

# Compare: batch mode (waits for completion)
yamlgraph graph run examples/demos/streaming/graph.yaml --var topic="streaming" --full
```

## What It Does

A two-node pipeline (draft → polish) that demonstrates real-time token output.
With `--stream`, you see tokens as they are generated by the LLM.
Without it, output appears only after both nodes complete.

## Key Concepts

- **`--stream` flag** — Uses `astream(stream_mode="messages")` under the hood
- **Graph-level streaming** — ALL LLM nodes stream automatically, no per-node config needed
- **Same graph, two modes** — The graph works identically with or without streaming

## Python API

For integration in servers or applications:

```python
from yamlgraph.executor_async import run_graph_streaming_native

async for token in run_graph_streaming_native("graph.yaml", {"topic": "AI"}):
    print(token, end="", flush=True)
```
