- **FR-995 Outsider Reader**: `scripts/outsider.sh <pr-number>` gives a PR description to a reader with no project context — title and body only, no files, no tools, run from a directory outside the repository on `gpt-5.6-sol` — and returns a four-section report: restatement in its own words, the model's own mergeability opinion (labelled non-authoritative), at most eight phrases it could not understand, at most ten things a merge decision would still need. The model's text is parsed into a typed report or rejected (fail closed); the YES/NO verdict is derived in code (≤ 2 unclear phrases and no hedge in the restatement), never taken from the model. Validated runs against real PRs append attributable ledger rows to `docs/census/outsider-ledger.jsonl`; `--input` and `--selftest` runs do not. Advisory and manual; `--comment` is the only path that posts to the PR. The reader is deliberately hard to please and not stable run-to-run at the borderline (the positive fixture derived NO then YES on identical input two minutes apart) — one run per PR, read by a human, never a loop to YES. Skill bundle `.github/skills/outsider-view/`; graph and prompt copied from the 2026-09-05 spike via `scripts/author.sh`. (REQ-YG-660, REQ-YG-661, REQ-YG-662, REQ-YG-663)
