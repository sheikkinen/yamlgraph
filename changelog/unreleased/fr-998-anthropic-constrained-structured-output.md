- **FR-998 Anthropic structured output is constrained, not requested**: `claude-sonnet-4-5` under the library-default forced tool call returned `list[str]` schema fields as one string (a markdown bullet list; 3/3 probe runs) and Pydantic killed the run with `list_type`. Structured-output binding now lives in one module, `yamlgraph/utils/structured_output.py`, which selects Anthropic's constrained decoding (`method="json_schema"`, 2/2 probe runs correct) for Anthropic chat models, forwards an explicit method unchanged, and leaves every other provider on the library default. When Anthropic answers a typed HTTP 400 saying the model does not support `output_config`, the sync and native-async helpers make exactly one forced-tool-call second attempt and log one INFO line; every other error propagates unchanged. The executor, the race node (its second attempt gets its own LangSmith run id) and both agent finalisation tiers route through the policy; provider identity and error classification live at the provider boundary in `yamlgraph/utils/llm_provider_identity.py`. Dependency floors: `langchain-anthropic>=1.5.1` (earliest verified for `json_schema`/`output_config.format`), `anthropic>=0.96.0` declared for the lazily imported typed error. (REQ-YG-664)
