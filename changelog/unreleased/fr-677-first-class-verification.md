- **FR-677 First-Class Verification (Move 1)**: Guards are now honored on all side-effect node types — shell `tool`, `python`, and `agent` — not just llm/router/copilot. `guards.pre` runs before execution (halt raises, skip returns a skip state, warn logs) and `guards.post` runs after (halt raises, retry re-executes bounded by `max_retries`, warn logs, pass returns output unchanged). Guard halts are never swallowed by `on_error: skip`. Declaring `guards:` on a node type that cannot honor them (map, race, subgraph, tool_call, passthrough, interrupt) now fails loud at compile time with `GraphConfigError`. Shared guard runtime relocated to `utils.guard_runtime` so Layer-3 tool factories share one contract without crossing import boundaries. (REQ-YG-511)
- **FR-677 First-Class Verification (Move 2)**: Graphs may now declare a top-level `verify:` block — a list of deterministic rules (`{check, on_fail: warn|halt, message}`) evaluated once against final state before END. A terminal `__verify__` node is inserted at load time, redirecting every explicit `END` destination (scalar/list edges, router `routes`/`default_route`, `loop_exits`) through it. `on_fail: halt` raises with the rule message; `on_fail: warn` records a `PipelineError` in `state.errors` and continues. `retry` is not a valid graph-level action and is rejected at the loader boundary. Reuses the existing guard expression language — no new syntax. (REQ-YG-511)
- **FR-677 First-Class Verification (Move 3)**: `yamlgraph graph run --gate` lints the graph before executing and refuses to run on any error-level finding (exit 1, graph never compiled), while warning-level findings are reported but do not block. `--gate --json` emits the machine-readable lint report only when blocking, with no decorative stdout on success. The `W025` lint rule now also validates graph-level `verify:` expressions — non-executable checks, invalid `on_fail` (e.g. `retry`), and missing `check` are flagged offline. (REQ-YG-511)
