# Widen copilot-trailer-gate to reject ALL Co-authored-by trailers

The `copilot-trailer-gate` CI check only matches the literal string `Co-authored-by: Copilot`. A commit with `Co-authored-by: Test` bypassed it (audit 234). This is a `gate_checks_shape_not_substance` failure.

**Fix:** Change the gate regex to reject any `Co-authored-by` trailer regardless of the name value. The policy is 'no identity trailers' — not 'no Copilot trailers specifically'.

~3-line change in `.github/workflows/commitlint.yml`.

See: `docs/diary/2026-05-18-inquisitor-audit-234.md`
