# Fix watcher daemon git identity (Test <test@test.com> on main)

The Chaplain watcher daemon commits with placeholder identity `Test <test@test.com>` instead of the operator's canonical git identity. This has reached `main` in multiple commits (audits 231, 234).

**Fix:** Source `GIT_AUTHOR_NAME`/`GIT_AUTHOR_EMAIL` from `git config` in the watcher commit step. Abort if unconfigured rather than falling back to a generic identity.

**CI hardening:** Add an `author-identity-gate` to commitlint.yml that rejects PRs containing commits from blocklisted authors (`test@test.com`, etc.).

See: `.chaplain/inbox/inquisitor-author-identity.md`
