# Graph loader strict mode for Python tool load failures

## Problem
Graph compilation currently warns and continues when Python tool loading fails.

## Why
Warn-and-continue can defer breakage to runtime and produce partial graph behavior that is hard to diagnose.

## Scope
- Add strict/fail-fast mode for tool loading in `yamlgraph/graph_loader.py`.
- Default behavior decision should be explicit (strict by default in CI/dev preferred).
- Add tests for both strict and non-strict behavior (if both modes are retained).

## Acceptance Criteria
- Tool load failures can be configured to fail compilation immediately.
- Behavior is documented and covered by tests.
