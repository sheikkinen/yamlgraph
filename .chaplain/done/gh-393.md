# fix(fsm): run_and_dispatch missing phase-aware event resolution

## Problem

`yamlgraph/utils/fsm/graph_runner.py` `_resolve_event()` has no phase-aware check. ninchat_voice requires that when a completed graph's state contains `phase: "crisis"` (or another key present in `event_map`), that phase value maps directly to an FSM event — before falling through to the generic `event_map.get("done")` path.

ninchat_voice `_resolve_from_checkpointer_state()` implements this:

```python
phase = state_after.values.get("phase", "")
if phase and phase in event_map:
    return event_map[phase], payload
```

This is tested by `tests/test_nc187_phase_aware_event.py` (3 cases: crisis, done, fallthrough).

## Impact

Without this, migrating ninchat_voice to the shared runner (NC-285) would silently break crisis routing: a call with `phase='crisis'` in graph state falls through to `success_event` instead of `crisis_detected`. Correctness regression, not observability loss.

## Fix

In `_resolve_event()`, after interrupt check and before the `event_map.get("done")` fallthrough, add:

```python
# Phase-aware resolution: graph state phase key overrides generic done mapping
if isinstance(result, dict):
    phase = result.get("phase", "")
else:
    phase = ""

if phase and phase in event_map:
    logger.info("🎯 phase '%s' → %s", phase, event_map[phase])
    return event_map[phase]
```

The `result` dict passed to `_resolve_event` may not have state values — the phase is in `state_after.values`. The fix may need to accept `state_values: dict | None = None` as an additional parameter and read `phase` from there, similar to how `interrupt_pending` is passed in.

## Acceptance Criteria

- [ ] `_resolve_event` (or equivalent) checks graph state `phase` value against `event_map` on completion (non-interrupt path)
- [ ] `phase='crisis'` with `event_map={'crisis': 'crisis_detected'}` → returns `'crisis_detected'`
- [ ] `phase='done'` falls through correctly to `event_map.get('done')`
- [ ] Unknown / missing phase falls through unchanged
- [ ] Existing tests pass
