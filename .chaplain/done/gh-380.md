# fix(precommit): add Seed: marker check to diary-reflection-check hook

## Problem

The `diary-reflection-check` pre-commit hook and the CI `diary-gate` are inconsistent:

| Check | Pre-commit | CI |
|-------|-----------|-----|
| Unfilled stubs (`[What cognitive trap`, etc.) | ✅ | ❌ |
| `Seed:` marker present | ❌ | ✅ |

A diary file can pass pre-commit and be committed, only to fail CI when the PR is opened — because CI checks for a literal `Seed:` marker that pre-commit never validates.

This is the **detection without enforcement** trap: the gate exists at CI but is absent at the earliest possible boundary (commit time).

Observed in: PR #379 (FR-378) — diary file had `Seed` under a `## Seed` heading but lacked the inline `Seed:` text token. Pre-commit passed; CI diary-gate failed with `diary reflection missing Seed: marker`.

## Proposed Fix

Extend the `diary-reflection-check` hook in `.pre-commit-config.yaml` to also verify that any staged `docs/diary/*reflection*.md` file contains the literal string `Seed:`.

Example check to add:
```bash
MISSING_SEED=
if [ -n "$MISSING_SEED" ]; then
  echo "❌ Diary reflection missing Seed: marker:"; echo "$MISSING_SEED"; exit 1
fi
```

## Acceptance Criteria

- [ ] Staging a diary reflection file without `Seed:` causes pre-commit to fail
- [ ] Staging a diary reflection file with `Seed:` passes
- [ ] Pre-commit and CI diary-gate agree on all valid/invalid cases
- [ ] Test in `tests/unit/test_precommit_hooks.py` or equivalent
