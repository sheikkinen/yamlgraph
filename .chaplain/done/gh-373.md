# Substance validation for diary-gate and changelog-gate

## Problem

Two CI gates check shape (filename presence in diff) but not substance:

1. **diary-gate** accepts any file matching `docs/diary/.*reflection.*fr-NNN`. A 1-byte file passes.
2. **changelog-gate** accepts any file in `changelog/unreleased/`. An empty file passes.

Both are compliance theatre — they block PRs without verifying the artifact conveys information.

The **demo-gate** already demonstrates the correct pattern: `demo_log_semantics.sh` validates non-emptiness, absence of fatal markers, and presence of success markers. This is the model.

## Proposed fix

Add semantic validation functions (modelled on `validate_demo_output_log_file`):

### diary-gate substance checks
- File is non-empty (contains non-whitespace)
- Contains at least one `##` header
- Contains a `Seed:` marker (required by the Distill rite)
- Minimum size threshold (e.g., >100 bytes — a meaningful reflection cannot be shorter)

### changelog-gate substance checks
- File is non-empty
- Contains YAML front matter (`---` delimiters with `type:` field)
- Contains at least one `- ` list item in the body

## Evidence
