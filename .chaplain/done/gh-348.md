# feat: yamlgraph skill export — portable Skills standard packaging

## Problem

YAMLGraph graphs are structurally equivalent to the open Skills standard (gaining traction in 2026), but there's no way to export them in that format. Agents (Claude Code, Cursor, Copilot) that support Skills discovery can't find YAMLGraph graphs without MCP configuration.

## Proposal

Add `yamlgraph skill export <graph_dir> --format skill-md` CLI command that generates a self-contained Skills directory from any graph.

## Output Structure

```
output/<name>/
├── SKILL.md              ← YAML frontmatter + markdown instructions
├── scripts/run.sh        ← yamlgraph graph run invocation
├── references/           ← Prompts rendered to markdown
└── assets/schema.json    ← Input/output JSON Schema
```

## Key Insight

YAMLGraph is a Skills authoring framework that doesn't know it yet. The MCP server is the 'live' integration; skill export is the 'portable' integration. No new graph YAML schema required — everything needed already exists in discovery.py.

## Format Variants

- `skill-md` — Standard open Skills directory (any agent)
- `copilot` — `.copilot/skills/<name>/SKILL.md` (VS Code Copilot)
- `cursor` — `.cursor/skills/<name>/` (Cursor)
