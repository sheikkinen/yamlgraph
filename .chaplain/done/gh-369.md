# feat(fsm): add snapshot.py and hook points to YamlgraphAsyncAction for Phase 2 subclassing

## Problem

`yamlgraph/utils/fsm/action.py` (Phase 1 of FSM bridge extraction) is complete but lacks two things needed for Phase 2 voicebot migration:

1. **`snapshot.py`** — `SnapshotParams` dataclass and `snapshot_params()` factory (planned in `plan-fsm-bridge-extraction.md` but not created)
2. **Hook points** in `YamlgraphAsyncAction` — extension points so subclasses can inject domain behaviour without duplicating the dispatch loop

Without these, `ninchat_voice` cannot subclass the shared action because its domain concerns (metrics, timing, staleness gating, utterance clearing) have no injection point.

## Planned module layout (from extraction plan)

```
yamlgraph/utils/fsm/
├── snapshot.py   # SnapshotParams dataclass + snapshot_params() factory  ← MISSING
└── action.py     # hook points: on_success, on_error, pre_dispatch, pre_snapshot ← MISSING
```

## Required changes

### `yamlgraph/utils/fsm/snapshot.py` (new)

```python
@dataclass
class SnapshotParams:
    graph_path: str
    initial_state: dict
    input_key: str
    output_key: str
    event_key: str
    event_map: dict[str, str]
    success_event: str
    failure_event: str
    thread_id: str | None
    phase: str = "graph"          # default; voicebot overrides via _llm_phase()
    payload_keys: list[str] | None = None

def snapshot_params(params: dict, context: dict, *, project_root: Path | None = None) -> SnapshotParams:
    """Validate and resolve action params into a frozen snapshot."""
    ...
```

### `yamlgraph/utils/fsm/action.py` — hook points

Three overridable hooks, no-op by default:

| Hook | Signature | Use case |
|------|-----------|---------|
| `on_success` | `(snap, event, elapsed_ms, context)` | Metrics, timing |
| `on_error` | `(snap, exc, elapsed_ms, context)` | Error counters |
| `pre_dispatch` | `(snap, event, payload, context) -> bool` | Staleness gating (return False to suppress) |
| `pre_snapshot` | `(params, context)` | Utterance clearing before snapshot |
