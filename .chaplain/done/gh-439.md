# Python tool path root confinement for file-based tools

## Problem
Path-based Python tools execute any resolved file path without graph-root confinement.

## Why
Even with trusted configs, this permits accidental execution from unrelated directories and weakens reproducibility.

## Scope
- Enforce `config.path` resolution within `graph_root` for Python tools in `yamlgraph/tools/python_tool.py`.
- Return clear error when path escapes root.
- Add tests for in-root pass and out-of-root fail.

## Acceptance Criteria
- Out-of-root Python tool paths fail at load time.
- In-root paths continue to load.
- Regression tests added and passing.
