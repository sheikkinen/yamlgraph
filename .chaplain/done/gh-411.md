# FR-409: Re-integrate Inquisitor into Watcher2 FSM

The Inquisitor was integrated into the old `watch.sh` (FR-261) but lost when the watcher was rebuilt as the FSM-based system (FR-296/305). 27-day audit gap proves the regression.

**Design:** Add `auditing` state to `watcher-dispatcher.yaml`. The existing `syncing_inbox` action checks `time.time() - context['last_audit_ts'] >= 86400` and emits `audit_needed` instead of `no_topics` when 24h has elapsed. New `audit_action.py` runs `.chaplain/inquisitor.sh --propose` and updates `last_audit_ts`.

**Change surface:** 3 files — dispatcher YAML (state + events + transitions), syncing inbox action (time check), new `audit_action.py`.

**Status:** Approved + judged. See `feature-requests/FR-409-inquisitor-watcher2-reintegration.md`
