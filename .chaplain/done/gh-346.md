# Extract shared FSM bridge to yamlgraph/utils/fsm (Phase 1)

## Problem

`yamlgraph_async_action.py` exists in three copies (fsm-router example, voicebot production, Chaplain). The fsm-router and voicebot share ~120 lines of identical core logic. The example has already drifted behind production once (FR-204).

## Objective

Extract the shared FSM↔YAMLGraph bridge into `yamlgraph/utils/fsm/` as part of the existing `[fsm]` optional dependency. Update the fsm-router example to use the shared module.

**This is Phase 1 only** — voicebot upgrade is a separate follow-up (see `projects/ninchat_voice/docs/plan-fsm-bridge-extraction.md`).

## Scope

### Create `yamlgraph/utils/fsm/`

```
yamlgraph/utils/fsm/
├── __init__.py          # Public API exports
├── helpers.py           # json_safe, extract_event, resolve_context_ref
├── event_sender.py      # FsmEventSender (AF_UNIX DGRAM)
├── ui_activity.py       # emit_ui_activity (UI_EVENTS_ENABLED gated)
├── graph_runner.py      # build_graph_input, resolve_graph_event (cascade)
├── snapshot.py          # SnapshotParams dataclass + snapshot_params (phase defaults to "graph")
└── action.py            # YamlgraphAsyncAction(BaseAction) with 3 hooks
```

### Hook design (3 hooks, minimal)

| Hook | When | Use case |
|------|------|----------|
| `on_success(snap, event, elapsed_ms, context)` | After successful dispatch | Metrics |
| `on_error(snap, exc, elapsed_ms, context)` | After failure dispatch | Error counters |
| `pre_dispatch(snap, event, payload, context)` | Before socket send | Staleness gating |

### Update fsm-router example

Replace `examples/fsm-router/actions/yamlgraph_async_action.py` (~295 lines) with thin import from `yamlgraph.utils.fsm`.

### Tests

1. Port `examples/fsm-router/tests/test_yamlgraph_async_action.py` to test the shared module
2. Unit tests for `helpers.py` (`extract_event`, `json_safe`, `resolve_context_ref`)
3. Unit tests for `graph_runner.py` (event resolution cascade with mocked graph)

### Update reference doc

Update `reference/patterns/fsm-as-conductor.md` to reference the shared module.

## Constraints

- `statemachine-engine` is already in `[fsm]` optional — no `pyproject.toml` change needed
- `SnapshotParams.phase` defaults to `"graph"` — `_llm_phase` is domain logic, stays in voicebot
- Chaplain's subprocess variant (`.chaplain/actions/`) is architecturally different — not touched
- No voicebot changes in this phase
