# fix(watcher): replace create_subprocess_shell with create_subprocess_exec in yamlgraph_async

FR-319 added shlex.quote() to sanitize var values passed through create_subprocess_shell(), but the root cause persists: the shell layer itself is unnecessary. The action already has structured cmd_parts — passing them through /bin/sh via create_subprocess_shell(" ".join(parts)) is a boundary violation.

Replace asyncio.create_subprocess_shell(command_string) with asyncio.create_subprocess_exec(*cmd_parts) in .chaplain/actions/yamlgraph_async_action.py. This eliminates shell interpretation entirely. Remove shlex.quote() (no longer needed when there is no shell).

Direct follow-up to FR-319 (#311). FR-319 constraint #4 explicitly deferred this: 'Keep create_subprocess_shell() call pattern intact in this FR.'
