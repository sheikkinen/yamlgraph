# feat: yamlgraph agent export — .agent.md generation with tool-scoped personas

## Problem

`yamlgraph skill export` (FR-348) produces SKILL.md files, but Copilot ignores them — the default agent considers them irrelevant because it believes it can handle the task natively. Skills describe capabilities; agents constrain behavior via tool restriction and persona isolation.

The missing layer: `.agent.md` export — dedicated Copilot agent modes scoped to YAMLGraph MCP tools, with persona, constraints, and tool restrictions that prevent the agent from bypassing the pipeline.

## Insight

Skills that **describe** are ignored. Agents that **constrain** are adopted. The `.agent.md` format provides:
- **Tool restriction** (`tools: [yamlgraph/*]`) — agent CAN'T do anything except call yamlgraph
- **Persona** — "You are a telephony operator" — model adopts the role
- **User invocation** — `@outcaller` — no activation heuristic needed

## Proposal

Add `--format agent-md` to `yamlgraph skill export` (or new `yamlgraph agent export` subcommand) that generates `.agent.md` files for Copilot agent modes.

### Output

```
.github/agents/outcaller.agent.md
```

With frontmatter:
```yaml
---
description: 'Make outbound AI voice calls via Twilio + ElevenLabs...'
tools: [yamlgraph/*]
model: 'Claude Sonnet 4'
---
```

### Agent Integration Stack

```
Layer 4: AGENTS.md / .agent.md  — WHO (persona + tool restriction)
Layer 3: A2A                     — WHERE (endpoint discovery)
Layer 2: Skills                  — WHEN + WHY (activation triggers)
Layer 1: MCP                     — HOW (callable functions)
Layer 0: copilot-instructions    — CONTEXT (ambient awareness)
```

## Acceptance Test: Call Me Maybe

End-to-end proof that the full stack works:

1. Export `outcaller-yamlgraph` graph as `.agent.md`
2. Install at user level or workspace level
3. In Copilot chat, invoke `@outcaller`
4. Say: "Call +358454913431 and greet them"
5. The agent delegates to `yamlgraph graph run` via MCP
6. A real Twilio call is placed
7. The voicebot at +358454913431 answers and converses

This proves the complete chain: agent mode → MCP delegation → yamlgraph execution → Twilio → ElevenLabs → real phone call.
