# Reference doc: LLM-as-gate pattern

Create `reference/patterns/llm-as-gate.md` documenting how to use a router node with a binary schema as a semantic gate.

**Pattern:** A router node with structured output (`verdict: pass|fail`, `reason: str`) implements the semantic gate primitive without any new framework code. The predicate is expressed as a YAML prompt template. The routing edge maps verdict values to next steps.

**Contents:**
- Problem statement: bash gates check shape (file exists, exit code 0) but not meaning
- Solution: an LLM node with a Pydantic schema that returns a structured pass/fail verdict
- Example graph snippet showing the pattern (router + binary schema + routing edges)
- When to use this vs. mechanical checks (grep, file existence)
- Composition: chaining gates, fallback on fail, retry semantics

**Motivation:** The Chaplain FSM's `semantic_gate` action type implements this pattern in application code. This doc shows that the framework already provides the primitive — no new action types or node types needed. A router node + structured output + routing edges = gate.
