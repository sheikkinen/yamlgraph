# fix: change context planner provider to inception/mercury-2

## Problem

The context planner pre-node (FR-337) uses `model: gemini-2.0-flash` which requires `GOOGLE_API_KEY`. This key is not reliably available in the pipeline subprocess environment, causing enforce failures (gh-339 failed with "Could not resolve authentication method").

## Fix

Change the context planner node in `.chaplain/graphs/watcher-enforce/enforce-session.yaml`:

```yaml
plan_context:
  type: llm
  prompt: context-planner
  provider: inception
  model: mercury-2
  temperature: 0
```

Mercury-2 is a fast, cheap model suitable for the classification task. `INCEPTION_API_KEY` is already available in `.env`.
