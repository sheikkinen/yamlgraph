# feature: watcher2 should reuse existing PRs

## Description
Currently, watcher2 fails if a PR already exists for the worktree branch. It should be updated to check for an existing PR and reuse/update it instead of blindly calling `gh pr create`.

## Context
This is based on findings from issue #180 where redundant PR creation attempts caused failures in the automated workflow.

## Acceptance Criteria
- [ ] watcher2 checks if a PR exists for the current branch before trying to create one.
- [ ] If a PR exists, watcher2 updates the existing PR (if needed) or simply proceeds.
- [ ] watcher2 does not exit with an error when a PR already exists.
