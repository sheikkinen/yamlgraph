# Retire old pipeline scripts (FR-273 Phase 5)

Replace watch.sh, enforce_worktree.sh, and bugfix_worktree.sh with watcher2.sh as the sole orchestrator.

## Old scripts to remove
- .chaplain/watch.sh (monolithic watcher, replaced by watcher2.sh)
- scripts/enforce_worktree.sh (enforcement, replaced by watcher2 enforce pipeline)
- scripts/bugfix_worktree.sh (bugfix flow, replaced by watcher2 enforce pipeline)

## Failure path forensics (from acceptance test)
Current failure paths destroy evidence: worktree_teardown + rm topic file on every failure. Fix:
- **Success** -> teardown worktree, delete topic, write metrics
- **Failure** -> keep worktree for inspection, move topic to .chaplain/failed/ (not delete), write metrics with worktree path. Human decides: inspect, retry, or discard.
- worktree_setup.sh should prune orphaned worktree metadata (git worktree prune) before branch creation
- Remove worktree_teardown and rm -f TOPIC_FILE from all failure branches in watcher2.sh

## Acceptance criteria
- All three old scripts deleted
- Any references to them updated (README, docs, CLAUDE.md)
- watcher2.sh is the documented entry point
- Failure paths preserve worktree + topic for forensic inspection
- No functional regression (watcher2.sh covers all old capabilities)
