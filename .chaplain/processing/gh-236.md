# Pre-commit pytest hook should exclude slow tests

The pre-commit pytest hook currently runs all unit tests including those marked `@pytest.mark.slow`. This causes commits to hang when slow tests take too long (observed: pytest hook stuck indefinitely during a shell-only commit).

**Current behavior** (line 228 of `.pre-commit-config.yaml`):
```
entry: bash -c '.venv/bin/python -m pytest tests/unit/ -q --tb=short --no-cov'
```

**Expected behavior**:
```
entry: bash -c '.venv/bin/python -m pytest tests/unit/ -q --tb=short --no-cov -m "not slow"'
```

Add `-m "not slow"` to the pre-commit pytest entry so slow tests are excluded from the commit hook. Slow tests should be run separately or in CI.
