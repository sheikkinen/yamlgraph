# 2026-09-25: An incident record is not eight research records

The map-plan investigation caught a real multi-branch LangGraph handler failure and traced a believable path toward resumable maps. That strength made adjacent proposals look settled. On judgement, the same document was cited by eight FRs, but most had not compared solution classes for their own decision. A correct incident witness did not settle a global retry policy, a safe default concurrency budget, or permission for lint to import user code.

Trap: treating one dense plan as transferable authority for all its proposed fixes. The plan can establish a failure; the FR still has to delimit its own decision and evidence. FR-1065 was different: its five solution classes and open experiments supported investigation authority, not implementation.

Heuristic: judge each proposed boundary separately. When a common source is cited across FRs, ask what it actually proves for this FR, then test whether the accepted contract can be asserted without implementing its neighbor.

**Seed:** Could a future plan-to-FR index explicitly map each witnessed failure to the decision it supports, exposing both uncovered decisions and duplicate authority before judgement?
