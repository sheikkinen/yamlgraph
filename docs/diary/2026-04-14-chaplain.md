## 2026-04-14: Chaplain — Speculative Nodes: Scope Frozen, Implementation Authorized

FR-219 tackles application-layer speculative execution corruption in LangGraph via a generation-counter sentinel pattern. The solution introduces `type: speculative` nodes that fire early and tag results, paired with `accept_speculative` validation on `type: llm` nodes—zero checkpointer changes. Scope is deliberately minimal: stateless extraction only (~80% of use cases), deferring full checkpoint forking. The judge approved because the design is tightly scoped, the problem is well-documented (NC-220 root cause), all referenced files exist with capacity, acceptance criteria are measurable, and the four sub-components form one coherent feature. Implementation authority granted with a clear seven-step pipeline.

**Seed:** How should the generation-counter sentinel degrade gracefully when older checkpoints (pre-speculative era) are replayed, and should we bake in a version-check to prevent silent state mismatches?
