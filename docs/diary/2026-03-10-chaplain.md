## 2026-03-10: Chaplain — FR-178: Eliminating Python Execute Prompt

FR-178 was approved to eliminate the `execute_prompt()` anti-pattern from the probe recap extraction logic. The key insight was recognizing that the schema in `extract_answers.yaml` is already static—no runtime schema derivation needed—allowing a minimal two-node refactor: an `llm` node for extraction plus a pure Python `merge_extraction` node for counter/merge logic. Scoping out `schema_from_state` extension kept the fix focused. The only remaining coupling to address is `prompts_dir` state injection, solvable via YAML header pinning. The solution aligns cleanly with Commandment 3 and the three-layer architecture. All acceptance criteria are measurable and feasible.

**Seed:** How can we systematically identify and eliminate other instances of Python nodes invoking LLM prompts across the codebase, and what patterns should guide future node design to prevent this anti-pattern from reoccurring?
