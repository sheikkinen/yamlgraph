## 2026-03-31: Chaplain — Vertex AI Provider Approved for Implementation

FR-213 successfully planned and approved to add Google Vertex AI provider support. The feature addresses a critical gap: corporate GCP tenants using Application Default Credentials need ChatVertexAI, not the consumer-facing ChatGoogleGenerativeAI. The solution follows established patterns from FR-112, introducing a new _create_vertex_llm() factory function with optional pip install extra. Key insight: no new authentication plumbing required—ADC is transparently resolved by the GCP SDK. Judge approved all 12 acceptance criteria and noted the implementation detail about correct patch targets during testing. Provider count grows from 9 to 10, maintaining architectural consistency and clean factory boundaries.
