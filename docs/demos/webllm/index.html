Essay critique — in your browser, no API key

A yamlgraph prompt (reflexion/prompts/critique.yaml, inline Pydantic schema) compiled mechanically to a WebLLM response_format and run entirely in this tab. This spike proves schema fidelity only — semantic quality of the critique is out of scope (FR-731 F6).

This browser has no WebGPU (navigator.gpu is absent). Works in: Chrome/Edge 113+ and Safari 26+ on macOS, Chrome on Windows/Android with a supported GPU. Firefox: not yet.
