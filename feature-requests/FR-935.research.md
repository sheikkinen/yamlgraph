## Preserved disagreement

The subtractionist position — remove the capability from the credential
instead of filtering the command — is genuinely stronger on
unbypassability and is not refuted, only deferred: it requires
credential separation between operator and agents that does not exist
in this workspace today. If FR-935's guard is ever witnessed bypassed
(e.g. by an agent invoking the GitHub API directly rather than `gh pr
merge`), the subtraction candidate becomes the mandated escalation, not
a new debate.
