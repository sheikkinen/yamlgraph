   subtractionist say the runner. FR-1122 chooses the runner: the graph
   already holds `_map_verdict` and the failures list, and printing them
   is presentation.

   `on_error: skip` "is read on both 0.6.0 and main", so the migration

   both, but the collected shape differs — on 0.6.0 a skipped branch

   item), because the tolerated/untolerated classifier is FR-1073's.
   The FR therefore gates the flat-item prompt on the release and relies
   on FR-1121 for interim loudness.
