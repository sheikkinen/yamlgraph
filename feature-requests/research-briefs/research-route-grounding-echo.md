# Problem brief: research-route grounding comes only from the author's brief

**Prior art:** dispositioned in the FR this brief produces (closed-input
brief per FR-890 R-2).

## Problem statement

The FR-890 research sole route gives every planner persona exactly four
strings copied from the author's problem brief. No committed repository
context — architecture record, capability registry, changelog, diary
index, source tree — reaches any persona; the single exception is a
one-line inventory of demo graph descriptions supplied to one persona.
Repository knowledge therefore enters a run solely through whatever the
author typed into the brief's constraints and incidents sections — that
is, through the very contaminated context window the closure was built
to escape. Convergence between personas is then partly an echo of the
author's framing rather than independent discovery, yet convergence is
counted as signal when authority is granted. World-precedent coverage
per run is a single web citation selected by a cheap model and never
reconciled against the search tool's actual recorded results, so a
fabricated URL passes the shape gate. The distinct-class gate counts
self-declared free-text class labels, so an honest convergence of three
personas on one class fails the run while cosmetic relabeling of the
same idea passes it. Finding cells have no length ceiling and arrive as
multi-hundred-word prose, hostile to the read-first discipline the
artifact exists to serve. Net effect: the route can produce
confirmation-with-ceremony — the author's first idea laundered through
five apparently independent voices — which is a stronger false signal
to the judge than no research at all.

## Classification

judgement/analysis/generation

## Constraints

- The closure boundary is non-negotiable: no persona may ever see the
  author's draft solution, prior discussion, or live session context;
  anything added to persona context must be committed,
  author-independent repository state.
- Enforcement in the deny path stays deterministic stdlib — no LLM
  verdicts in brief preflight or artifact verification.
- All LLM nodes stay pinned to a cheap haiku-class model at
  temperature 0; per-run cost must stay in pennies so the route can run
  for every FR without budget pressure.
- Disagreement must remain visible as separate rows and must not be
  voted away; genuine convergence must not by itself fail a run.
- The artifact must remain mechanically checkable against a frozen
  schema AND readable by a human in one sitting.
- The prospective judge doctrine clause (research evidence before
  authority) and the promotion lifecycle to
  feature-requests/FR-XXX.research.md remain in force.
- The route remains a blocking one-command run, minutes not hours, no
  daemon (CAP-113 death mode).
- Cited web precedent must be traceable to an actual tool observation
  recorded during the run, not merely well-formed.
