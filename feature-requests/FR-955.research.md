Preserved disagreement: safe-by-default opt-in reduction (three personas,
chosen) vs mandatory declaration with no default (subtractionist, class 2).
The subtractionist's point stands as a lint posture: when a branch falls
back to full state, the author must be told.

`is_this_a_graph`: no. Four personas: compile-time payload contract at
the fan-out boundary; a projection node authored ahead of the map cannot
change what `Send` carries (class 4). The librarian's "yes" refers to
Step Functions' Parallel state being a graph primitive whose *edge*
carries the filter — the same placement class 1 chooses inside the
compiler, not a YAML-authored alternative.
